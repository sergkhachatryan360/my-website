ALTERATIONS BY GEORGE — WEBSITE

Files:
- index.html: page content and structure
- style.css: design, layout and responsive breakpoints
- script.js: mobile navigation, service detail popups, gallery lightbox and reveal effects

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Recommended: install the Live Server extension, right-click index.html and choose "Open with Live Server".
